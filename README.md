# Чудо Обувь — система оформления заказов

Приложение для оформления заказов обуви торговой компании «Чудо Обувь».

## 1. Название приложения

**Чудо Обувь** — система оформления заказов обуви.

## 2. Используемые технологии

- **Язык программирования:** Python 3.8+
- **GUI-фреймворк:** PyQt6
- **СУБД:** PostgreSQL 12+
- **Драйвер БД:** psycopg2-binary
- **Работа с Excel:** openpyxl
- **Операционная система:** МосТехОС ROSA (Linux)

## 3. Назначение и основные функции

Приложение реализует систему оформления заказов обуви со следующими возможностями:

### Каталог товаров
- Отображение карточек товаров: изображение, производство, наименование, категория, состав, цена со скидкой, суммарное количество по всем размерам
- Подсветка светло-красным цветом моделей с остатком ≤ 3.
- Автоматический расчёт цены со скидкой 25% для товаров, на которые не было заказов за предыдущий календарный месяц

### Авторизация
- Вход по логину (без пароля) для пользователей из списка
- Роли: Администратор, Менеджер, Авторизованный пользователь
- Возможность входа без авторизации 

### Работа с каталогом
- Фильтрация по категории товара
- Поиск по наименованию и описанию 
- Сортировка по цене 
- Просмотр подробной информации о товаре
- Выбор доступного размера и количества пар

### Оформление заказов
- Добавление нескольких позиций в заказ
- Изменение количества и удаление позиций в корзине
- Подтверждение заказа с сохранением в БД
- Автоматическое уменьшение остатков на складе

### Управление заказами (Менеджер, Администратор)
- Просмотр списка заказов (дата, ФИО клиента, итоговая сумма).
- Просмотр состава заказа с расчётом итоговой суммы.
- Создание новых заказов из каталога.
- Удаление заказов с подтверждением.
- **Администратор:** редактирование даты заказа, удаление отдельных позиций.

## 4. Порядок подготовки базы данных и запуска приложения

### Требования

- Python 3.8.13
- PostgreSQL 12.22
- Установленные библиотеки: `PyQt6`, `psycopg2-binary`, `openpyxl`

### Команда для установки нужных программ:

sudo dnf -y update && sudo dnf install python3-pip -y && sudo pip3 install pyqt6 psycopg2-binary openpyxl && sudo dnf install vscode && sudo dnf install -y dbeaver && sudo dnf install libreoffice && sudo dnf install -y postgresql postgresql-server postgresql-devel && postgres --version && sudo systemctl start postgresql12 && systemctl status postgresql12 --no-pager (Если команда прервалась, скопировать ее после момента где остановилась и заново запустить,пропустив тот элемент, где выдало ошибку, так как скорее всего нужное уже установлено )

### Запуск приложения:

В случае правильной распаковке архивированного файла проекта и правильной установке нужных для его запуска компонентов сделать следующее:
Открыть BDeaver и создать базу данных с названием chudo_obuv
1.В VScode перейти в папку проекта
2.Открыть database.sql , скопировать код, открыть новый скрипт в BDeaver (в базе данных chudo_obuv), вставить код и нажать alt + x
3.Использовать команду python3 sql/import_all.py
4.Использовать команду python3 main.py

После этого приложение запустится.
